# 空中航法　計算盤不要問題集

自家用操縦士 学科試験の過去問（平成30年〜令和5年）および2026年6月CBT例題集の**空中航法**から、**航法計算盤（フライトコンピューター）が不要な問題だけ**を抽出し、重複論点を排除してまとめたもの。  
**除外した問題**：航法ログ連問（GS/CH/WCA/予定飛行時間）、CAS⇔TAS変換、「航法計算盤を利用した換算値」——いずれも風力三角形をE6Bで解く問題。  
**収録**：知識問題＋暗算で解ける計算（1 in 60のDA・俯角・燃料・緯度・経度時刻・QNH誤設定など）。CBT（2023年11月〜）はこの範囲から出題。  
各問の見出し右の `出典` は元の試験期・問番号。選択肢はチェックボックス、**正答・解説は折りたたみ**。

## A. 航法の基礎・図法

**問1**　`出典: R8例題集 問1`

航法の 3 作業について誤りはどれか。
- [ ] （１）航空機の位置を確認すること。
- [ ] （２）航空機の針路を算出すること。
- [ ] （３）所要の地点における到達時刻を予想すること。
- [x] （４）所要の地点における消費燃料の量を予想すること。
:::spoiler 正答
4

**用語**  
・航法の3作業＝航空機を目的地へ導くための基本作業で、①位置の確認、②針路の算出、③到達予定時刻の予想の3つをいう。  
① 位置の確認 … 正。航法3作業の一つ。  
② 針路の算出 … 正。航法3作業の一つ。  
③ 到達時刻の予想 … 正。航法3作業の一つ。  
④ 消費燃料量の予想 … 誤。燃料計画は飛行計画上重要だが、航法の3作業には含まれない。  
:::

**問2**　`出典: R8例題集 問2`

地文航法の説明で正しいものはどれか。
- [x] （１）地形地物と地図を見比べながら飛行する方法である。
- [ ] （２）飛行中の風を求め、針路の決定や速度と経過時間により位置を推測しながら飛行する方法
である。
- [ ] （３）航法援助施設からの電波を受信して位置や針路を求めて飛行する方法である。
- [ ] （４）管制機関と通信を設定し、常に管制機関の指示に従って飛行する方法である。
:::spoiler 正答
1

**用語**  
・地文航法＝地上の地形・地物を地図と照合して自機位置を確認しながら飛行する航法。  
① 地形地物と地図を見比べながら飛行 … 正。地文航法の定義そのもの。  
② 風を求め針路決定、速度と経過時間から位置を推測 … 誤。これは推測航法（Dead Reckoning）の説明。  
③ 航法援助施設の電波で位置・針路を求める … 誤。これは無線航法の説明。  
④ 常に管制機関の指示に従い飛行 … 誤。管制指示に従うことは航法の種類ではない。  
:::

**問3**　`出典: R8例題集 問7`

メルカトル図及びランバート図について誤りはどれか。
- [x] （１）メルカトル図における緯度の間隔は緯度が高くなるほど小さくなる。
- [ ] （２）メルカトル図における子午線は平行で直線は航程線になる。
- [ ] （３）ランバート図における子午線と平行圏の接線は直交している。
- [ ] （４）ランバート図における直線は大圏と見なして実用上差し支えない。
:::spoiler 正答
1

**用語**  
・メルカトル図＝子午線が平行直線となる正角円筒図法で、直線が航程線（一定針路の線）になる。ランバート図＝正角円錐図法で、直線を実用上大圏と見なせる。  
① メルカトル図の緯度間隔は高緯度ほど小さくなる … 誤。高緯度ほど拡大されるため緯度の間隔は大きくなる。  
② 子午線は平行で直線は航程線 … 正。メルカトル図の特徴。  
③ ランバート図で子午線と平行圏は直交 … 正。正角図法の性質。  
④ ランバート図の直線は大圏と見なせる … 正。実用上大圏として扱える。  
:::

**問4**　`出典: R2-7 問7`

航空図について誤りはどれか。

- [ ] ① メルカトル航空図では、赤道と子午線以外の大圏は、赤道から遠ざかる曲線になる。
- [x] ② メルカトル航空図では、子午線が平行で航程線は直線である。
- [ ] ③ ランバート航空図では、大圏はほぼ直線で、最短距離に近いコースが得られる。
- [ ] ④ ランバート航空図では、航程線が極に引きつけられる曲線になる。

:::spoiler 正答
4

① 正。赤道と子午線以外の大圏は、赤道から遠ざかり極側にふくらんだ曲線になる。  
② 正。子午線は平行な直線で、航程線（等角航路）も直線になる。  
③ 正。大圏はほぼ直線に描かれ、最短距離に近いコースが得られる。  
④ 誤。ランバートでは航程線は大圏（直線）より低緯度側（赤道側）へふくらむ曲線であり、「極に引きつけられる曲線」は誤り。  
:::

**問5**　`出典: R元-11 問7`

ランバート航空図で２地点間の方位を最も正確に測定する方法で正しいものはどれか。

- [x] ① 出発地に近い子午線を使用する。
- [ ] ② 2地点間の航程線に近い子午線を使用する。
- [ ] ③ 2地点間の中分子午線もしくは、中間付近の子午線を使用する。
- [ ] ④ 目的地に近い子午線を使用する。

:::spoiler 正答
3

**用語**  
・ランバート（円錐図法）は正角図で図上の直線はほぼ大圏に一致するが、各子午線が真北に対しなす角は場所ごとに異なる。  
・大圏（グレートサークル）＝地球上の2点間を結ぶ最短経路。  
・航程線（等角航路）＝すべての子午線と一定の角度で交わる経路。大圏より距離は長くなる。  

① 誤。始点付近の子午線では方位に誤差を生じる。  
② 誤。方位は航程線ではなく大圏（直線）で測るべきで、基準もこれではない。  
③ 正。2地点の中間の子午線を用いると大圏方位を最も正確に測れる。  
④ 誤。終点付近でも誤差を生じる。  
:::

**問6**　`出典: R2-3 問8`

航空図に記される「－－－　7°Ｗ　－－－」の記号の意味で正しいものはどれか。

- [ ] ① 羅北が真北より7度西にある。
- [x] ② 磁北が真北より7度西にある。
- [ ] ③ 羅北が磁北より7度西にある。
- [ ] ④ 真北が磁北より7度西にある。

:::spoiler 正答
2

**用語**  
・偏差＝真北と磁北のなす角。航空図の等偏差線に「7°W」と記される。  
・羅北＝機上の磁気コンパスが指す北（自差の影響を受けた方向）。  

① 誤。羅北（コンパスの指す方向）と磁北の差は自差であり偏差ではない。  
② 正。偏差7°Wは磁北が真北より7度西側にあることを示す。  
③ 誤。これは自差の説明。  
④ 誤。西偏差では真北は磁北より東側。記述が逆。  
:::


## B. 高度・対気速度・高度計

**問7**　`出典: R8例題集 問3`

高度についての説明で正しいものはどれか。
- [x] （１）気圧高度は、標準気圧面 29.92inHg からの航空機の高度である。
- [ ] （２）密度高度は、平均海面から航空機までの実際の高度である。
- [ ] （３）真高度は、標準大気の密度に相当する航空機の高度である。
- [ ] （４）絶対高度は、平均海面から航空機までの垂直高度である。
:::spoiler 正答
1

**用語**  
・気圧高度＝標準気圧面（29.92inHg）を基準とした高度。真高度＝平均海面からの実際の高度。絶対高度＝地表面（直下の地面）からの高度。密度高度＝そのときの大気密度に相当する標準大気中の高度。  
① 気圧高度は標準気圧面29.92inHgからの高度 … 正。定義どおり。  
② 密度高度＝平均海面からの実際の高度 … 誤。これは真高度の説明。密度高度は現在の大気密度に相当する標準大気中の高度。  
③ 真高度＝標準大気の密度に相当する高度 … 誤。これは密度高度の説明。  
④ 絶対高度＝平均海面からの垂直高度 … 誤。絶対高度は地表面からの高度。平均海面からの高度は真高度。  
:::

**問8**　`出典: R5-3 問12`

IAS一定で飛行したときのTASの変化について誤りはどれか。

- [ ] ① 空気密度が減少するとTASは増加する。
- [ ] ② 気圧高度が低くなるとTASは減少する。
- [x] ③ 外気温度が低くなるとTASは増加する。
- [ ] ④ 風向、風速が変化してもTASは変化しない。

:::spoiler 正答
3

**用語**  
・IAS一定でもTASは空気密度で変わる（TAS＝IAS÷√σ、密度が小さいほどTASは大きい）。  

② 正。低高度は密度が大きくTASはIASに近づく。  
③ 誤。低温は密度が「大きく」なるためTASは「減少」する。記述が逆。  
④ 正。風は対地速度に影響し対気速度TASは変えない。  
:::

**問9**　`出典: R5-3 問10`

着陸前に入手したQNH「29.87inHg」に対し、誤って「29.78inHg」の値を気圧高度計にセットした。着陸する飛行場の標高が670 ftのとき、着陸後に気圧高度計が示す値に最も近いものはどれか。

- [ ] ① 490 ft
- [ ] ② 580 ft
- [x] ③ 661 ft
- [ ] ④ 760 ft

:::spoiler 正答
2

**用語**  
・高度計は気圧規正値を約1inHgあたり約1,000ft換算で指示する。  

① 誤。補正量が合わない。  
② 正。正しい29.87より0.09inHg低い29.78をセットしたため指示は約90ft低くなり、標高670ft−90ft≒580ftを示す。  
③ 誤。補正されていない。  
④ 誤。逆方向に補正している。  
補足: 0.09inHg×1,000ft/inHg≒90ft。低い気圧をセットすると指示高度は低くなる。  
:::

**問10**　`出典: R2-11 問10`

A空港を出発して２時間後に地上気圧の下がったＡ空港に着陸した。気温の変化がなく高度計のＱＮＨを変えずに着陸した場合、正しいものはどれか。

- [ ] ① 高度計は出発時よりも低く指示する。
- [x] ② 高度計は出発時よりも高く指示する。
- [ ] ③ 高度計の指示は出発時と変わらない。
- [ ] ④ 高度計は絶対高度を指示する。

:::spoiler 正答
2

**用語**  
・QNHを変えないと、気圧高度計は当地の真の気圧変化を補正できない。  

① 誤。逆である。  
② 正。地上気圧が下がったのにQNHを出発時のまま（高いまま）にすると、高度計は実際より高い高度を指示する。  
③ 誤。気圧が下がった分だけ指示は高くなる。  
④ 誤。QNHセットは平均海面からの高度を指示する規正であり絶対高度ではない。  
補足: 気圧が約1inHg下がると指示は約1,000ft高くなる。  
:::

**問11**　`出典: R2-3 問17`

対気速度計の指示に誤差を生じさせないものはどれか。

- [ ] ① ピトー管取付位置
- [ ] ② 空気密度
- [x] ③ 空気の圧縮性
- [ ] ④ 風速

:::spoiler 正答
4

**用語**  
・対気速度計は動圧（全圧−静圧）から対気速度を示す。  
・圧縮性誤差＝高速飛行時、空気の圧縮性の影響により生じる対気速度計の指示誤差。  

① 誤。取付位置による誤差（位置誤差）を生じる。  
② 誤。密度によりIASとTASに差（密度誤差）を生じる。  
③ 誤。高速では圧縮性誤差を生じる。  
④ 正。対気速度計は対気速度を測るため風速は指示誤差の原因とならない。  
補足: 設問は「誤差を生じさせないもの」を問うており、④が該当する。  
:::


## C. 位置・方位・偏流（暗算で解ける計算含む）

**問12**　`出典: R8例題集 問4`

緯度について正しいものはどれか。
- [ ] （１）緯度 1°は約 1 nm である。
- [ ] （２）緯度 1°は約 1 km である。
- [x] （３）緯度 1°は約 60 nm である。
- [ ] （４）緯度 1°は約 60 km である。
:::spoiler 正答
3

**用語**  
・緯度＝赤道を0°として南北に測った角度。緯度1分（1′）の子午線上の距離が1海里（nm）と定義的に対応する。  
① 緯度1°≒1nm … 誤。1nmに相当するのは緯度1分。  
② 緯度1°≒1km … 誤。  
③ 緯度1°≒60nm … 正。1°＝60分、1分≒1nmなので1°≒60nm。  
④ 緯度1°≒60km … 誤。60nm≒111kmであり60kmではない。  
補足: 1nm＝1,852m。緯度1°≒60nm≒111km。  
:::

**問13**　`出典: R5-3 問9`

方位及び針路について誤りはどれか。

- [ ] ① 航空機の位置からある地点への方向を、機位を通る子午線の真北から測定した水平角度を真方位（TB）という。
- [ ] ② 航空機が地表上を飛行した軌跡の真方位を真航路（TC）という。
- [ ] ③ 航空機の機首尾線と磁気子午線のなす角を磁方位で表したものを磁針路（MH）という。
- [x] ④ 航空機の機首方向を基準に測定した物標の方位を相対方位（RB）という。

:::spoiler 正答
2

① 正。機位を通る子午線の真北から測った、ある地点への水平角。  
② 誤。実際に飛行した軌跡の真方位は「真対地針路（トラック）」であり、真航路（TC）は予定コースを指す。軌跡の方位をTCとするのは誤り。  
③ 正。機首尾線と磁気子午線のなす角を磁方位で表したもの。  
④ 正。機首方向を基準に測った物標の方位。  
:::

**問14**　`出典: R8例題集 問10`

偏差・自差について正しいものはどれか。
- [x] （１）真北に対して磁北が西を指していれば偏差 W という。
- [ ] （２）磁北に対して羅北が西を指していれば自差 E という。
- [ ] （３）日本付近の偏差は 6°～8°E であるが、年月と共に変化していて流動的である。
- [ ] （４）適切に整備された磁気羅針儀であれば自差が生じることはない。
:::spoiler 正答
1

**用語**  
・偏差（Variation）＝真北と磁北のなす角。自差（Deviation）＝磁北と羅北（コンパスが指す北）のなす角。  
① 真北に対し磁北が西なら偏差W … 正。磁北が真北の西側にあれば西偏差（W）。  
② 磁北に対し羅北が西なら自差E … 誤。羅北が磁北の西側なら自差W。Eは東側の場合。  
③ 日本付近の偏差は6°～8°E … 誤。日本付近の偏差はおおむね4°～10°の西偏（W）である。年月とともに変化する点は正しいが方向が誤り。  
④ 適切に整備すれば自差は生じない … 誤。機体の磁気や電気系統の影響による自差は完全には除去できず、自差修正カードで補正する。  
:::

**問15**　`出典: R8例題集 問9`

TH 300°で飛行中、 10 nm 飛行して 1.0 nm 右側にオフコースした。このときの DA として正
しいものはどれか。ただし、WCA は 0°とする。
- [ ] （１）3° R

- [x] （２）6° R
- [ ] （３）3° L
- [ ] （４）6° L
:::spoiler 正答
2

**用語**  
・TH（真針路）＝真北を基準とした機首方位。DA（偏流角）＝針路と航跡のなす角。WCA（風修正角）＝風に流されないよう針路に加える修正角。オフコース＝予定コースからの横ずれ。  
① 3°R … 誤。  
② 6°R … 正。  
③ 3°L … 誤。  
④ 6°L … 誤。  
補足: 1 in 60ルールにより、ずれ角≒60×横ずれ距離÷飛行距離＝60×1.0÷10＝6°。右に流されているので偏流角は6°R。WCA＝0°なのでTHがそのまま予定コースであり、航跡とのなす角がDAとなる。  
:::

**問16**　`出典: R5-3 問17`

TC 253°のコースをWCA＋7°として飛行したところ、TRは255°となった。このときのDAとして正しいものはどれか。

- [ ] ① 3° L
- [ ] ② 3° R
- [x] ③ 5° L
- [ ] ④ 5° R

:::spoiler 正答
3

**用語**  
・DA（偏流角）＝実際の対地針路（TR）と機首方位（TH）の差。  

TH＝TC＋WCA＝253＋7＝260°。TR＝255°。  
① 誤。  
② 誤。  
③ 正。DA＝TR−TH＝255−260＝−5°で、機首方位より5°左へ流された（5°L）。  
④ 誤。方向が逆。  
:::

**問17**　`出典: R8例題集 問11`

対地高度 4,500 ft で飛行中、チェックポイントを真横下方（俯角） 45 度に視認した。このとき
の自機からチェックポイントまでの水平距離に最も近いものはどれか
- [ ] （１）0.5 nm
- [x] （２）0.8 nm
- [ ] （３）1.3 nm
- [ ] （４）1.8 nm
:::spoiler 正答
2

**用語**  
・対地高度（AGL）＝地表面からの高度。俯角＝水平線から下向きに測った角度。  
① 0.5nm … 誤。  
② 0.8nm … 正。  
③ 1.3nm … 誤。  
④ 1.8nm … 誤。  
補足: 俯角45°では水平距離＝高度（tan45°＝1）。よって水平距離＝4,500ft。1nm＝6,076ftなので4,500÷6,076≒0.74nm≒0.8nm。  
:::

**問18**　`出典: R3-11 問10`

CH045°で飛行中、Ｅ駅が１時半の方角に見えた。このときの自機の位置として正しいものはどれか。
